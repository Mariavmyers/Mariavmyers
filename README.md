### QueryTrends.ai — Search & AI Discoverability

An independent project helping businesses understand website signals relevant to search and AI discoverability.

- Developed with AI coding assistance.
- Includes Discovery Scout, a website readiness scanner.
- Uses rule-based checks and weighted category scores.
- Examines SEO health, speed, Google readiness, Bing readiness, and AI/LLM readiness.
- Integrates Google PageSpeed Insights through a Cloudflare Worker.
- Provides readiness assessments; these scores do not establish actual rankings or appearances in AI answers.
